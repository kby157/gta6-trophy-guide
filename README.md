Leonida Platinum Tracker — an offline trophy guide and progress tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies (names, descriptions and grades verbatim) each carry a guide written for this app with its sources named (Exophase, PSNProfiles, GTABase, Push Square, PowerPyx): what the published guides pin down is cited, and what they do not is said so instead of invented. It flags the one trophy published guides call possibly missable (Positive Mental Attitude) and the five stranger finales that close with story progress, walks a five-stage roadmap to the platinum, tracks counters (stunts, shooting-range golds, meditation spots and more), hides story trophies behind a spoiler setting until you earn them, and saves, exports and imports your progress — all in the browser, with no network requests. Open it with `?demo=1` to see it with sample progress loaded.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a browser
```
